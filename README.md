This repository contains my implementation for various distributed systems algorithms.

The [flyio](/flyio) directory has solutions to fly.io's [Gossip Glomers](https://fly.io/dist-sys/), which are tested using Jepsen's [Maelstrom](https://github.com/jepsen-io/maelstrom). The challenges are also described in the Maelstrom repo [here](https://github.com/jepsen-io/maelstrom/tree/main/doc).

The [protohackers](/protohackers) directory has solutions to protohackers.com problems.

Both sets of challenges are good fun!
